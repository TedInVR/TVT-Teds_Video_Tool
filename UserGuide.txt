Ted's Video Tool (TVT) 0.8.17

Install and update
For the first upgrade from VFLR, use the installer in the GitHub README.
On Mac, the first installation builds TVT.app in Applications. It requires Apple
Command Line Tools and uses the Homebrew FFmpeg and ffprobe already installed
at /opt/homebrew/bin. VFLR Development, also in Applications, holds temporary
update files. Completed installations remove those files.

On Windows, TVT is installed per user in %LOCALAPPDATA%\Programs\VFLR
and opens from the Start menu. Install Git for Windows, Gyan FFmpeg,
and MediaInfo CLI with the commands in the GitHub README. The Mac
version uses Homebrew MediaInfo CLI (brew install media-info).

Use Help > Check for Updates for a manual check. TVT also checks at
launch on Mac and every 15 minutes while open on both systems. When
offered an update, choose Quit and Install Update. TVT shows that it
is preparing the update, then closes, installs it, and reopens.
Help > TVT User Guide opens the guide included with the installed version.

Load files and choose a tool
The square TVT app icon also appears beside Ted's Video Tool for 2D, 3D and VR.
Drop files from Finder or File Explorer onto the TVT window. On Mac,
you can also drop them onto the TVT app icon. A drop loads the files
without starting a job. Browse is another way to load files. A new
selection replaces the current one. Clear empties the selection.
The current file name or file count is shown at the top of the window.

For Join Parts or Link Videos, drop all the clips together. With several
files loaded, a single-file tool asks which of those files to use.
You can also click a tool first and choose the source in a file dialog.
Download Online takes a page URL. Add Subtitles still asks for a
subtitle file or an online search, even when the video is already loaded.

Tools are grouped into Edit and Assemble, Picture and Format,
Audio and Subtitles, and Inspect and Download. A pulsing blue banner
names the active job. Green confirms completion and red marks a failure.
After an export, click Show Result to reveal the file in Finder or
File Explorer. The banner indicates activity without estimating progress.

Batch processing
Drop or browse for multiple videos, then choose Upscale Video, Convert
Video, or Extract or Remove Audio. Pick the settings once and select a
destination folder. TVT works through the files one at a time, shows
the current file, its number in the batch, and its estimated encoding
percentage when available. TVT reports any failures at the end. Other files
continue if one fails. Existing outputs are kept; TVT adds a number
when two output names would match. Show Result reveals the output folder.
With one video, these tools still ask for a specific output filename.
The percentage describes the current file and may pause while TVT
finishes saving it. Trim Clip and layout exports also show an estimate.

Import Disc Backup
Install and open MakeMKV once. Drop an ISO, a VIDEO_TS or BDMV folder,
a folder containing one of those folders, or VIDEO_TS.IFO / index.bdmv
onto TVT. Choose Edit and Assemble > Import Disc Backup. TVT scans
the disc. If there are several titles, the longest is suggested;
check the running time for alternate cuts, episodes or extras.

Original MKV copies the title using a profile that requests original
audio, subtitles, chapters and MVC when present. Choose it for 2D or
if you are unsure how the picture is laid out. For known packed 3D,
choose Full or Half Over-Under to convert to Full Side-by-Side, or
Already Side-by-Side to copy and tag the existing picture. If unsure,
export Original MKV and look at a frame with Trim Clip. Two images
one above the other indicate Over-Under. Two side by side indicate SBS.
Disc subtitle tracks remain selectable, with their original placement.

If the title reports MVC Blu-ray 3D, choose MVC Blu-ray 3D to Full
Side-by-Side. Install and open Docker Desktop once (use Apple silicon
on an M-series Mac and Linux containers on Windows). See
docs.docker.com/desktop/. If native mvc2sbs is on PATH, TVT uses that
instead. Otherwise TVT runs the upstream converter image from
ghcr.io/brunoga/mvc2sbs. The first run can download the image. TVT
checks the converter before extracting a disc title.

If you already saved an Original MKV containing MVC 3D, load that
MKV in Import Disc Backup to convert it directly to Full Side-by-Side.
The original MKV stays intact. Docker Desktop may ask for access to
the input or output folder. Choose an output folder with room for
the temporary files and the new MKV.

Choose an output location with enough room for the extracted title
and a second file if converting 3D. TVT removes temporary files after
the import. Menus are not included. MakeMKV must be working under its
own licensing and disc support. No MakeMKV license is bundled with TVT.


Trim Clip
Load a video and choose Trim Clip in Edit and Assemble. Scrub the
timeline to see a preview frame. Use -0.1 s and +0.1 s to fine-tune
the position. At the beginning of the section, click Mark Start. At
the end, click Mark End. The colored range bar shows the selection.
Click Export Clip and choose MP4, MKV, MOV, WebM, AVI, or MPEG-TS.
The original file stays in place.

The trim editor accepts local videos with a readable duration that
FFmpeg can decode. Previews show the packed picture, including both
eyes of SBS or Over-Under footage or the source VR projection. Exports
preserve that picture layout. MKV is the default. TVT re-encodes the
main video and audio tracks so the cut can begin between keyframes.
Subtitle tracks and chapters are omitted. Player-specific VR or 3D
metadata may need to be restored separately for automatic detection
on a headset or player.

Split Movie
Pick a video and choose 2–12 roughly equal parts. TVT splits at nearby
keyframes, copying the first video stream and all audio tracks without
re-encoding. The MP4 parts are saved in a folder beside the original.
On Mac, you can also drag one video onto the app to split it.

Join Parts
Choose all matching numbered parts. TVT sorts the numbers and shows the
order before copying the streams into one MP4. Check the list before continuing to make sure every part is included.

Link Videos
Select two or more clips and pick their playback order. The first clip sets
the frame size and rate. Different shapes are fitted with black padding.
TVT includes the full clips, including credits and recaps. Each clip
contributes its first audio track in stereo or silence if it has no audio.
The output is an H.264 MP4 with AAC audio.

Upscale Video
Choose 1080p (up to 1920×1080) or 4K (up to 3840×2160). TVT uses Lanczos
scaling and preserves the picture proportions. For example, 4:3 video
becomes 1440×1080 at 1080p. Exports use H.264 MP4 and retain audio tracks
as AAC. Link and Upscale omit subtitles.

Video exports go where you choose or,
for Split and Join Parts, beside the inputs. On Mac, app and update files live
in Applications.


MediaInfo
Choose a media file, then Summary, Full Details, or JSON. TVT runs the
official MediaInfo CLI and displays its output inside the app. Reports
include the available container, video, audio, subtitle and chapter data,
such as codecs, resolution, frame rate, bitrate, color details, language
tags and channel layouts. Full Details shows additional fields supplied
by MediaInfo. On Mac, press Command-A then Command-C to copy the full
report, or use Edit > Select All and Edit > Copy. On Windows, click
Copy Report.

Convert Video
Choose a local video and select a preset. TVT accepts formats and
codecs supported by your FFmpeg build, including many MP4, MKV, MOV,
AVI, WebM, MPEG, MTS and TS files. Output choices:
  MP4    H.264 video / AAC audio
  MKV    H.264 video / AAC audio / original subtitle tracks
  MOV    ProRes 422 video / PCM audio
  WebM   VP9 video / Opus audio
  AVI    MPEG-4 video / MP3 audio
  MPEG-TS H.264 video / AAC audio

Conversion re-encodes the primary video and each audio track. For subtitles,
choose MKV. Attachments (including subtitle fonts) and additional video
tracks are omitted. Use the existing Join Parts operation for matching
numbered files that can be joined by stream copy.


Download Online
Paste one video page URL, then choose Video (MKV) or Audio Only (MP3).
TVT uses yt-dlp, the same download engine used by Stacher. Supported
sites and formats depend on yt-dlp and the page. Private, protected, or
sign-in-only videos may be unavailable. Download material you have
permission to save. Install yt-dlp and Deno using the GitHub README.
Choose the save location for every download.

Extract or Remove Audio
Choose MP3, M4A, FLAC, or WAV to export the first audio track as a
separate file. Choose Remove audio to create a silent MKV. That option
copies video and compatible subtitle streams without re-encoding them.

Add Subtitles
Choose a 2D video or the matching full/half Side-by-Side or Over-Under
layout (left eye first). Choose a local SRT, ASS, or WebVTT text file,
or use OpenSubtitles, Subtitle Cat, or SubDL. TVT defaults to embedding
subtitles as a selectable track in a new MKV with " English subtitles"
added to the movie name. Edit the suggested name in the Save dialog
when needed. TVT copies the video and audio. The new track starts
disabled unless the player's subtitle preferences select it.

For 3D, Save a separate ASS file is also available. This is useful when
VLC shows a blank embedded track. Save the ASS beside the original
movie with the same base name. If VLC does not load it automatically,
use Subtitles > Add Subtitle File and select it.
Text files are normalized to plain timed text, so original ASS styling
is not carried forward.

In 3D, each timed cue is drawn in both eye images. Slightly forward is
the default, with more forward placement or screen depth also available.
The setting is a fixed offset for the whole film. Play in a player or
mode that renders positioned ASS over the packed image before splitting
it for 3D display. A player that overrides ASS placement may display
the two copies incorrectly. Check a short scene on your usual 3D setup.

Search Subtitle Cat
Choose Search Subtitle Cat and enter a short film or episode title. TVT
opens the results in your browser. Pick a matching release, download the
SRT in your language, then return to TVT and select the downloaded file.
This route uses no OpenSubtitles key or downloads. Some subtitles may
be machine translated. Check the translation and timing on your video.

Download from SubDL
1. Create a free API key in your SubDL account panel. The key is separate
   from your OpenSubtitles key.
2. Save SubDL.json as plain text containing {"api_key":"YOUR_SUBDL_KEY"}.
   Mac location: /Applications/VFLR Development/SubDL.json
   Windows location: %LOCALAPPDATA%\Programs\VFLR\SubDL.json
3. Choose Download from SubDL, then enter a short movie title and year,
   an IMDb ID such as tt2124046, or a show title followed by S01E01.
   Use EN for English. TVT downloads the first matching release archive
   and uses its SRT. Check timing against your video. If an archive has
   multiple SRTs, download it in your browser and choose the right file
   through Local subtitle file. Python 3 is required.

OpenSubtitles setup
1. Make an account at opensubtitles.com and create a key in your
   profile's API Consumers section (www.opensubtitles.com/consumers).
2. Save a file named OpenSubtitles.json containing:
   {"api_key":"YOUR_API_KEY"}
   Mac location: /Applications/VFLR Development/OpenSubtitles.json
   Windows location: %LOCALAPPDATA%\Programs\VFLR\OpenSubtitles.json
   Keep the file local. If your account uses a REST API bearer token,
   you can add a "token" field. The provider controls download quotas.
3. Choose Search OpenSubtitles and enter the film title and year, or a
   series title followed by S01E01, plus a language code such as en.
   TVT tries a file hash match first, then downloads the best available
   title match and adds it to the MKV. Check timing when a title match
   comes from a different release. Local subtitles work without a key.
   Python 3 is required for online lookup and stereo subtitle authoring.

Change Aspect or Stereo Layout
For 2D footage, choose 16:9, 4:3, 1:1, or 9:16. TVT adds black padding
to fit the whole picture. For 3D footage, choose the current and desired
layout. The converter supports Full SBS, Half SBS, Full Over-Under,
and Half Over-Under in left-eye-first order. Choose Half SBS as the
output to reduce Full SBS to half the packed width. Output is H.264
MKV with audio copied. Add 3D subtitles after converting the layout so
the subtitle positions match the new frame.


AI Restore (Apple Silicon Mac)
Drop an SDR video into TVT and choose AI Restore in Picture and Format.
Choose Install AI Engine on the first run. If needed, run
brew install python@3.12 in Terminal and retry. SeedVR2 and its weights
are stored in /Applications/VFLR Development. The first restoration
downloads several gigabytes of weights. There is no charge, trial,
subscription, or account. Your video is processed locally.

The entire video is selected by default. Use Mark Start and Mark End
if you want to restore only a section. On the image, drag boxes around
faces, lettering, or blurred people you want to preserve. Boxes stay
in the same position for the selected range. Scrub through that range
to check where people move. Clear Boxes removes all boxes.

Preview 5 Seconds is optional and shows the start of the selection.
Compare the original on the left and the restoration on the right.
Close the comparison to return to the same selection and boxes.
Save Restored Clip saves the short sample if you want a copy.

Choose Restore Selection to restore the entire marked range or, with
the default selection, the whole video. Choose Gentle, Balanced, or
Strong and save an MP4. TVT blends the model result into the source,
preserves deep shadows and boxed areas, and keeps the first audio track.
Gentle applies the least AI detail. The banner shows the filename and restoration stage. Full exports
show the current SeedVR2 chunk and total while the model runs.
TVT asks for confirmation before starting a preview or restoration.
Cancel is the default. The full-restoration prompt shows the selected
duration and explains that an hour of video could take roughly a week
on an M2 Max, based on a real-world test. The load can interrupt other
work, including Shield3D playback. Use Preview 5 Seconds to judge a
sample before committing to a long job.
Long jobs run in batches and can
take substantial time and temporary disk space. There is no fixed
duration limit for Restore Selection.

This workflow is for SDR on Apple Silicon. It uses a reduced-resolution
AI pass and regular output encoding. Review AI details outside protected
areas. The MambaOFR scratch-repair research implementation requires CUDA
and is not included.

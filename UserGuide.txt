VFLR 0.4.0 — Video Fix Link Restore

Install and update
On Mac, the first installation builds VFLR.app in Applications. It requires Apple
Command Line Tools and uses the Homebrew FFmpeg and ffprobe already installed
at /opt/homebrew/bin. VFLR Development, also in Applications, holds temporary
update files. Completed installations remove those files.

On Windows, VFLR is installed per user in %LOCALAPPDATA%\Programs\VFLR
and opens from the Start menu. Install Git for Windows, Gyan FFmpeg,
and MediaInfo CLI with the commands in the GitHub README. The Mac
version uses Homebrew MediaInfo CLI (brew install media-info).

Use Help > Check for Updates for a manual check. VFLR also checks at
launch on Mac and every 15 minutes while open on both systems. On Mac,
choose Download Update and quit when it is ready. On Windows, confirm
the update and close VFLR. Reopen it from Applications or the Start menu
after installation. Help > VFLR User Guide opens
the guide included with the installed version.

Split Movie
Pick a video and choose 2–12 roughly equal parts. VFLR splits at nearby
keyframes, copying the first video stream and all audio tracks without
re-encoding. The MP4 parts are saved in a folder beside the original.
On Mac, you can also drag one video onto the app to split it.

Join Parts
Choose all matching numbered parts. VFLR sorts the numbers and shows the
order before copying the streams into one MP4. Choose each part explicitly
if the Finder drop list is incomplete.

Link Videos
Select two or more clips and pick their playback order. The first clip sets
the frame size and rate. Different shapes are fitted with black padding.
VFLR includes the full clips, including credits and recaps. Each clip
contributes its first audio track in stereo or silence if it has no audio.
The output is an H.264 MP4 with AAC audio.

Upscale Video
Choose 1080p (up to 1920×1080) or 4K (up to 3840×2160). VFLR uses Lanczos
scaling and preserves the picture proportions. For example, 4:3 video
becomes 1440×1080 at 1080p. Exports use H.264 MP4 and retain audio tracks
as AAC. Link and Upscale omit subtitles.

Finder reveals completed exports. Video exports go where you choose or,
for Split and Join Parts, beside the inputs. On Mac, app and update files live
in Applications.


MediaInfo
Choose a media file, then Summary, Full Details, or JSON. VFLR runs the
official MediaInfo CLI and displays its output inside the app. Reports
include the available container, video, audio, subtitle and chapter data,
such as codecs, resolution, frame rate, bitrate, color details, language
tags and channel layouts. Full Details shows additional fields supplied
by MediaInfo. JSON can be copied into another tool. Select and copy
report text on either platform.

Convert Video
Choose a local video and select a preset. VFLR accepts formats and
codecs supported by your FFmpeg build, including many MP4, MKV, MOV,
AVI, WebM, MPEG, MTS and TS files. Output choices:
  MP4    H.264 video / AAC audio
  MKV    H.264 video / AAC audio / original subtitle tracks
  MOV    ProRes 422 video / PCM audio
  WebM   VP9 video / Opus audio
  AVI    MPEG-4 video / MP3 audio
  MPEG-TS H.264 video / AAC audio

Conversion re-encodes the primary video and each audio track. For subtitles,
choose MKV. Attachments (including subtitle fonts) and additional video
tracks are omitted. Use the existing Join Parts operation for matching
numbered files that can be joined by stream copy.
